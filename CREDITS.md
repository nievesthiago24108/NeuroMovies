## Iconos de la aplicación

Derivados de la imagen de marca provista por el usuario. El archivo original
**no se modifica**; sólo se recorta el cerebro y se compone sobre un fondo
redondeado.

| Archivo | Tamaño | Uso |
| --- | --- | --- |
| `app/favicon.ico` | 16/32/48 | Pestaña del navegador |
| `app/icon.png` | 512×512 | Icono de la app (convención de Next.js) |
| `app/apple-icon.png` | 180×180 | iOS / Safari |
| `public/icons/icon-192.png` | 192×192 | Manifiesto PWA |
| `public/icons/icon-512.png` | 512×512 | Manifiesto PWA |
| `public/icons/maskable-512.png` | 512×512 | Manifiesto PWA (maskable) |

## Contenido de TMDB

Los pósters y las imágenes de fondo se sirven **en tiempo de ejecución** desde
`image.tmdb.org` (nunca se copian a este repositorio). El logo de TMDB
(`public/images/tmdb.svg`) es propiedad de TMDB y se usa según sus términos de
atribución, que se muestran en el pie de página de la aplicación:

> This product uses the TMDB API but is not endorsed or certified by TMDB.
